# Aetherle

Aetherle is a Wordle-style daily word puzzle plugin for Final Fantasy XIV using Dalamud.

## About

Guess the hidden FFXIV-themed word in 6 tries.

Each guess returns feedback:

green - Correct letter, correct position
yellow - Correct letter, wrong position
black - Letter not in the word

## How to use

Open the plugin with:

/aetherle

Type a guess and submit it.
